# Secure your supply chain (permitted registries, sign and validate artifacts, etc.)

This section covers: the admission pipeline, ValidatingAdmissionPolicy, permitted registries, webhooks and policy engines, and image signing with cosign.

The section has one module with a playground, four reading parts, a graded lab, a summary and a knowledge check.

## Learning Outcomes

- Place admission in the API request path.
- Write and test a permitted-registries policy.
- Compare webhooks, Kyverno and Gatekeeper and set failure policy.
- Sign and verify an image digest with cosign.
