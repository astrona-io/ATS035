# Understand your supply chain (e.g. SBOM, CI/CD, artifact repositories)

This section covers: supply chain stages, SBOMs with Syft, vulnerability scans with Trivy, CI/CD pipelines and artifact repositories.

The section has one module with a playground, four reading parts, a graded lab, a summary and a knowledge check.

## Learning Outcomes

- Trace the trust boundaries from source to deployment.
- Generate and read an SBOM in SPDX and CycloneDX formats.
- Scan an image and filter the result.
- Name controls for pipelines and registries and configure a registry credential.
